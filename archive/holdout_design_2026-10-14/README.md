# Archived: hold-out design (2026-10-14)

Code of the earlier design with an 80/20 hold-out split, eight hypotheses and resampling
in the main models. It was replaced on 2026-10-17 by the proposal protocol (nested
repeated cross-validation on all eligible records, see CHANGELOG.md). It never ran on the
real data. It is kept only as an audit trail, is not imported by the project and is not
maintained or tested.
